# 🏠 RoomieSync

A smart, interactive prototype built during today's hackathon to simplify the roommate matching process for students of JUIT. 

## 🚀 What it Does
* **Smart Matching:** Helps users discover highly compatible roommates based on lifestyle choices, habits, and preferences.
* **Seamless Interface:** Features a clean, interactive user experience built with modern web technologies.
* **AI-Powered Insights:** Uses **Google Gemini API** and advanced logic to streamline room-swap requests and campus living companions.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla ES6)
* **API / Tools:** Anti Gravity Platform, Gemini API
* **Environment:** Developed on Localhost

## 📂 Project Structure
* `index.html` - The core application entry point.
* `/css/` - Styling and responsive design components.
* `/js/` - Frontend engine including `app.js` and AI logic hooks (`gemini.js`).
